## About

StrandPath is designed to give students a clearer way to **explore options and understand possible directions**. It focuses on guidance and exploration rather than making decisions for the learner.

> **Guidance over prediction.** StrandPath is intended to support exploration, not choose a student's future for them.

## Prototype 1

### Current focus

Prototype 1 establishes the initial functional experience around:

* **Student pathway exploration**
* **Skills and interests assessment**
* **Assessment results**
* **Pathway information**
* **College and career exploration**
* **Guidance-oriented recommendations**

This stage is the project's **initial functional prototype**, providing the foundation for later research, refinement, testing, and development.

## Project Principle

StrandPath should help learners **understand their choices**, not make those choices for them.

Recommendations are therefore presented as guidance to explore possible alignment between a learner's interests, skills, strengths, and preferences and different pathway, college, or career options.

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Project Stage

**Current stage: Prototype 1**

Prototype 1 is the starting functional version of StrandPath. Future stages may expand the research basis, recommendation methodology, data structure, school-specific information, testing, and production implementation.

## Note

StrandPath is a prototype for guidance and exploration. Its recommendations should not be treated as a definitive prediction or instruction about a student's academic or career future.
