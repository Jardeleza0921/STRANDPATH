# StrandPath

StrandPath is a student pathway guidance web application designed to help learners explore possible Senior High School pathways, college fields, and career areas based on their interests, skills, and preferences.

The project is currently in **Prototype 1**.

## Project Status

**Prototype 1 — Initial Functional Prototype**

The current prototype focuses on:

- Student pathway exploration
- Skills and interests assessment
- Assessment results
- Pathway information
- College and career exploration
- Guidance-oriented recommendations

StrandPath is intended to provide guidance and exploration, not to make decisions for students.

## Technology

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
